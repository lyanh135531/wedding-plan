# Self-hosted Vietnamese fonts

- Be Vietnam Pro: Regular 400, Medium 500, SemiBold 600, Bold 700.
- Playfair Display: variable weight axis 400–900, normal style.

The WOFF2 files retain the complete character maps of the Google Fonts upstream
TTF files, including Vietnamese. They are served by this application; no runtime
Google Fonts/CDN request is required. Both families are distributed under the
SIL Open Font License; see `OFL.txt` inside each family directory.

Sources:

- https://github.com/google/fonts/tree/main/ofl/bevietnampro
- https://github.com/google/fonts/tree/main/ofl/playfairdisplay

Downloaded 2026-11-19 and converted losslessly to WOFF2 with fontTools/Brotli.
